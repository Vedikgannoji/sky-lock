### Gimbal Control Mode

AUTO and MANUAL must be real operating modes.

**AUTO:**
- The controller calculates target pointing and commands the gimbal.
- The gimbal slews according to the configured limits.
- The camera feed follows the actual commanded gimbal state.
- Tracking and telemetry reflect the actual state.

**MANUAL:**
- Automatic commands must not overwrite manual pointing commands.
- Manual pan/tilt input must affect the selected virtual camera immediately.
- Existing manual steering and keyboard controls must continue working.

**Live mode switching is mandatory.**

When switching MANUAL → AUTO, the actual controller must become active immediately and the camera feed must transition to automatic pointing.

When switching AUTO → MANUAL, automatic commands must stop, and the camera must remain under manual control.

Do not merely change the combo-box text. Do not reset the entire simulation or jump the gimbal to an unrelated orientation when switching modes.

Ensure safe transitions, coherent controller state, and no competing commands from two controllers.

### Camera FPS

The camera FPS setting must control the sensor-processing/rendering cadence where practical.

Changing FPS must affect the real frame/update schedule. Keep the GUI responsive and prevent uncontrolled timer creation or excessive CPU usage.

### Max Slew

The Max Slew setting must control actual gimbal movement in degrees per second.

Test that changing the value changes the maximum commanded angular movement. Use elapsed simulation time rather than assuming a fixed time step.

### Target settings and motion parameters

### Start, Stop, and Reset

- Start starts the configured runtime.
- Stop stops frame processing and control updates safely.
- Reset returns the applicable simulation, camera, gimbal, tracker, and disturbance state to their defined initial conditions.
- No duplicate worker loops or timers may be created.
- UI state must reflect actual runtime state.
